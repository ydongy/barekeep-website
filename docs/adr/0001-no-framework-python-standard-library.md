# 0001 No framework: pages are generated with the Python standard library only

- Status: accepted
- Date: 2026-10-03
- Related: [0005](0005-sitekit-vendored.md)

## Context

The site is a handful of pages in nine languages with one interactive piece (the download button). It is edited by a maintainer and AI collaborators, and a static framework would bring a Node toolchain, a lock file and a stream of dependency updates for markup that changes a few times a year.

## Decision

Pages are generated by Python scripts that use only the standard library, from `i18n/*.json` and `changelog.json`. The output is plain HTML, one stylesheet and two small scripts (`lang.js`, `download.js`), all committed in `public/`. There is no Node dependency and no build at deploy time.

## Cost

There is no component system, hot reload or bundler; layout lives in Python string templates and one hand-written `public/style.css`. New interactive features must be small enough to write by hand.

## Revisit triggers

The site needs more than a few interactive pieces, or a page type the string templates can no longer express clearly.
