# v1.0 security walkthrough

## What was checked

Recorded on 2026-10-03 against the `docs/standard-docs` branch, by reading the files named below.

| Area | What was inspected | Result |
|---|---|---|
| Response headers | `public/_headers`: Content-Security-Policy, `nosniff`, no-referrer | Present; no external host except the release feed in `connect-src` |
| Scripts | `public/lang.js`, `public/download.js` | No `innerHTML`; the feed values are written with `textContent`; the download link must start with `https://` |
| Cookies and storage | all scripts | No cookies; `localStorage` holds only the chosen language |
| Third-party content | generated pages, `check_site.py` | No third-party scripts, fonts or images; check passes |
| Redirects and aliases | `public/` | No `_redirects`, no alias pages; `check_facts.py` fails if one appears |
| Deploy config | `wrangler.jsonc` | `workers_dev` and `preview_urls` off; domain bound in the dashboard |
| Credentials in the repository | working tree and every commit, by pattern search | No key, token or private-key block found |

## Findings

None.

## History scan

A pattern search over every added line in all 18 commits of all branches (key and token assignments, private-key
blocks, common provider key prefixes) found no match, at commit 98220f8. This repository has no `scan_secrets.py`;
the pattern search is not a proof that no secret exists.

## Not covered

The Cloudflare dashboard settings (domain binding, the Git connection, access rules) and the R2 bucket's CORS rule,
which live outside this repository; the payment provider's pages; behavior of the release feed itself; a review by
an independent party.

python3 scripts/sitekit/check_site.py
