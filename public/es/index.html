Un archivo de código privado para tu Mac

Una bóveda de código privada que nunca se desconecta.

BareKeep mantiene tus repositorios de GitHub y GitLab replicados en tu Mac y puede enviarlos a tu propio servidor Git como copia de seguridad externa.

Tus repositorios, tus equipos.

  • Solo lectura en el origen

    Los datos solo fluyen del origen a este Mac y de ahí a la copia. BareKeep nunca escribe en GitHub ni en GitLab.

  • Los tokens se quedan en el llavero

    Los tokens de acceso viven en el llavero de tu Mac, uno por cada origen y por cada destino de copia, y se pasan a git mediante una tubería.

  • No se recopila nada

    Sin telemetría, sin informes de fallos, sin cuenta. Los espejos y el historial de ejecuciones se quedan en tu Mac.

  • Un repositorio Git de verdad

    Cada espejo es un repositorio bare completo en una carpeta que tú eliges. Clónalo cuando quieras, incluso sin conexión.

Cuando los historiales divergen, se detiene y te pregunta.

La copia solo acepta envíos fast-forward. Si se hizo un force-push en el origen, BareKeep conserva la copia tal como está, pausa la sincronización automática de ese espejo y te deja decidir si quieres sobrescribirla desde el origen.

  1. Origencon force-push
  2. Este Macal día
  3. Copiatiene otros commits, en espera

Cada espejo tiene su indicador.

La forma te indica el estado, así que puedes leerlo sin depender del color.

  • Sincronizado

    Al día con el origen.

  • Sincronizando

    Hay una ejecución en curso. Puedes cancelarla.

  • Divergente

    El historial del origen ya no coincide con la copia. No se sobrescribió nada.

  • Fallido

    La última ejecución falló. BareKeep explica el motivo con palabras claras y reintenta con espera progresiva.

  • En pausa

    En pausa a propósito. La sincronización manual sigue funcionando.

Funciona con los servidores Git que usas.

Los orígenes y los destinos de copia comparten la misma lista de plataformas, así que un servidor Gitea o Forgejo puede ser cualquiera de los dos.

  • GitHub
  • GitLab
  • Gitea
  • Forgejo
  • Instancias autoalojadas
  • Cualquier URL Git https

Configúralo en tres pasos.

  1. Pega la dirección de un repositorio

    BareKeep reconoce la plataforma, el propietario y el nombre del repositorio a partir de una dirección https o ssh.

  2. Elige una carpeta y un token

    Decide dónde vivirá el espejo en tu Mac. El token va directo al llavero.

  3. Añade un destino de copia (opcional)

    Apunta BareKeep a tu Gitea, Forgejo, GitLab o GitHub. Crea repositorios privados por ti y hace el envío después de cada sincronización.

Descarga BareKeep

BareKeep es una app de la barra de menús para macOS. Los espejos se ejecutan en segundo plano y la ventana principal muestra cada ejecución.

Para macOS 26.0 o posterior.

Descargar


Para verificarlo, compáralo con la salida de shasum -a 256 sobre el archivo descargado.

Abre el dmg y arrastra BareKeep a Aplicaciones. BareKeep usa el Git que viene con macOS; si este Mac aún no lo tiene, BareKeep te ofrece instalar las Command Line Developer Tools. ¿Tienes dudas? Lee las preguntas frecuentes.

Precio

BareKeep tiene una versión gratuita que gestiona hasta 3 espejos y Pro, una compra única sin límite. Una licencia Pro cubre todas las versiones 1.x. El precio se muestra aquí en el lanzamiento.
