Frequently asked questions

Can’t find your answer? BareKeep explains failures in plain words in the run log and on the mirror’s status card. Open the mirror first.

Basics

What is BareKeep?

A macOS menu bar app that keeps mirrors of your GitHub, GitLab, Gitea and Forgejo repositories on your Mac, and can push them to your own Git server as an off-site backup. Each mirror is a complete Git repository you can clone from at any time.

What do I need?

A Mac with macOS 26.0 or later, and Git. BareKeep uses the Git that comes with macOS; if the Command Line Developer Tools are missing, BareKeep shows a page that installs them for you (about 1 GB, from Apple). Mirrors and settings are untouched while Git is missing, and syncing resumes once it is installed.

Do I have to pay for BareKeep?

BareKeep has a free plan that manages up to 3 mirrors, and Pro, a one-time purchase (no subscription) with no such limit. One Pro license covers every 1.x version. See Pricing.

Can I use BareKeep on more than one Mac?

Yes. The free plan works on every Mac you own or control. A Pro license key can be active on 2 of your Macs at a time; to use it on another one, deactivate it in Settings › License on one of the two first.

Can I get a refund?

Yes, within 14 days of buying Pro, with no reason needed. The rules are in the Refund Policy.

What happens to my mirrors if my license stops working?

Nothing you have already mirrored or backed up is deleted, and the mirrors on your disk stay readable. BareKeep goes back to the free plan: the first 3 mirrors keep syncing, and the others stay where they are but are not synced until you upgrade.

Does BareKeep change my repositories on GitHub or GitLab?

No. Data only flows source, then this Mac, then backup. BareKeep never pushes to the source.

Which Git hosts work?

GitHub, GitLab, Gitea, Forgejo (including codeberg.org), self-hosted instances of the last three, and any https Git URL. Add a self-hosted instance in Settings › Platforms first; after that it can be a source or a backup target.

How do I get help?

Start with the run log and the status card of the mirror that has the problem: they explain failures in plain words. If that does not help, email support@barekeep.com and say what the status card shows. Never send an access token.

Syncing and backups

How does syncing work?

Sync Now runs a mirror immediately; a schedule runs them automatically. Failed runs retry with backoff, and the run log and each run’s output are on the mirror’s detail page. Pause Sync stops automatic runs; manual sync still works.

How does the backup work?

Add one or more backup targets (Gitea, Forgejo, GitLab or GitHub) and choose per mirror which ones it pushes to. Where the platform has an API, BareKeep creates the private repository for you. Backup is optional: without a target, the mirror stays on this Mac.

What does “Diverged” mean?

The backup has commits this mirror doesn’t have, for example after the source was force-pushed. To avoid overwriting them BareKeep does not push, and pauses automatic sync for that mirror. Check the backup, or choose Overwrite from Source… to reset its branches and tags to match the source. Commits that exist only in the backup are no longer referenced, so copy the local folder first if you want to keep them.

Privacy and security

Where is my access token stored?

Only in your Mac’s keychain, one entry per source and per backup target. It is not written to files or logs and does not appear in command lines or environment variables; it is handed to git through a pipe.

Does BareKeep collect any data?

No telemetry, no crash reports, no account. The only data BareKeep sends is the update check and, if you buy Pro, your license key and a device label to the payment provider. The Privacy Policy lists every address BareKeep connects to.

How does BareKeep update?

BareKeep checks for new versions once a day and when you ask (turn the daily check off in Settings) and installs them in the app after you confirm. Updates are free on both plans. The history of each version is on the Changelog.
