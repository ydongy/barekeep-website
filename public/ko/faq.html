자주 묻는 질문

원하는 답을 찾지 못하셨나요? BareKeep는 실행 로그와 미러의 상태 카드에서 실패 원인을 쉬운 말로 설명합니다. 먼저 해당 미러를 열어 보세요.

기본

BareKeep는 무엇인가요?

GitHub, GitLab, Gitea, Forgejo 저장소의 미러를 Mac에 보관하고, 오프사이트 백업으로 나만의 Git 서버에 푸시할 수 있는 macOS 메뉴 막대 앱입니다. 각 미러는 언제든 클론할 수 있는 완전한 Git 저장소입니다.

무엇이 필요한가요?

macOS 26.0 이상이 설치된 Mac과 Git이 필요합니다. BareKeep는 macOS에 포함된 Git을 사용하며, 명령어 라인 개발자 도구가 없으면 설치해 주는 페이지를 보여 줍니다(Apple 제공, 약 1 GB). Git이 없는 동안에도 미러와 설정은 그대로 유지되고, 설치되면 동기화가 다시 시작됩니다.

BareKeep은 유료인가요?

BareKeep에는 최대 3개의 미러를 관리하는 무료 플랜과, 이러한 제한이 없는 일회성 구매(구독 아님) Pro가 있습니다. Pro 라이선스 하나로 모든 1.x 버전을 사용할 수 있습니다. 가격을 참고하십시오.

BareKeep을 Mac 여러 대에서 사용할 수 있나요?

네. 무료 플랜은 본인이 소유하거나 관리하는 모든 Mac에서 사용할 수 있습니다. Pro 라이선스 키는 본인의 Mac 2대에서 동시에 활성화할 수 있으며, 다른 Mac에서 사용하려면 먼저 두 대 중 한 대의 설정 › 라이선스에서 비활성화하십시오.

환불받을 수 있나요?

네, Pro 구매 후 14일 이내에 이유 없이 가능합니다. 규정은 환불 정책에 있습니다.

라이선스가 작동하지 않게 되면 미러는 어떻게 되나요?

이미 미러링하거나 백업한 것은 삭제되지 않으며, 디스크에 있는 미러는 계속 읽을 수 있습니다. BareKeep은 무료 플랜으로 돌아갑니다. 처음 3개의 미러는 계속 동기화되고, 나머지는 그 자리에 남아 있지만 업그레이드하기 전까지 동기화되지 않습니다.

BareKeep가 GitHub나 GitLab의 내 저장소를 변경하나요?

아니요. 데이터는 소스, 이 Mac, 백업 순서로만 흐릅니다. BareKeep는 소스에 절대 푸시하지 않습니다.

어떤 Git 호스트를 지원하나요?

GitHub, GitLab, Gitea, Forgejo(codeberg.org 포함), 뒤의 세 가지의 자체 호스팅 인스턴스, 그리고 모든 https Git URL을 지원합니다. 자체 호스팅 인스턴스는 먼저 설정 › 플랫폼에서 추가하세요. 그러면 소스나 백업 대상으로 사용할 수 있습니다.

도움은 어떻게 받나요?

먼저 문제가 있는 미러의 실행 로그와 상태 카드를 확인하십시오. 실패 원인을 쉬운 말로 설명해 줍니다. 그래도 해결되지 않으면 support@barekeep.com로 이메일을 보내 상태 카드에 표시된 내용을 알려 주십시오. 액세스 토큰은 절대 보내지 마십시오.

동기화와 백업

동기화는 어떻게 작동하나요?

지금 동기화는 미러를 즉시 실행하고, 일정은 미러를 자동으로 실행합니다. 실패한 실행은 백오프로 재시도하며, 실행 로그와 각 실행의 출력은 미러의 상세 페이지에서 볼 수 있습니다. 동기화 일시 중지는 자동 실행을 멈추지만 수동 동기화는 계속 작동합니다.

백업은 어떻게 작동하나요?

백업 대상(Gitea, Forgejo, GitLab 또는 GitHub)을 하나 이상 추가하고, 미러마다 어느 대상에 푸시할지 선택하세요. 플랫폼에 API가 있으면 BareKeep가 비공개 저장소를 대신 만들어 줍니다. 백업은 선택 사항입니다. 대상이 없으면 미러는 이 Mac에만 남습니다.

“기록 불일치”는 무슨 뜻인가요?

백업에 이 미러에 없는 커밋이 있다는 뜻입니다. 예를 들어 소스가 강제 푸시된 경우입니다. 그 커밋을 덮어쓰지 않도록 BareKeep는 푸시하지 않고 해당 미러의 자동 동기화를 일시 중지합니다. 백업을 확인하거나, 소스로 덮어쓰기…를 선택해 브랜치와 태그를 소스와 같게 되돌리세요. 백업에만 있던 커밋은 더 이상 참조되지 않으므로, 보관하려면 먼저 로컬 폴더를 복사해 두세요.

개인정보 보호와 보안

액세스 토큰은 어디에 저장되나요?

Mac의 키체인에만 저장되며, 소스와 백업 대상마다 항목이 하나씩 만들어집니다. 파일이나 로그에 기록되지 않고, 명령줄이나 환경 변수에도 나타나지 않으며, 파이프를 통해 git에 전달됩니다.

BareKeep는 데이터를 수집하나요?

원격 측정, 충돌 보고, 계정이 없습니다. BareKeep이 보내는 데이터는 업데이트 확인과, Pro를 구매한 경우 라이선스 키 및 기기 이름표를 결제 대행사에 보내는 것뿐입니다. 개인정보 처리방침에 BareKeep이 연결하는 모든 주소가 나와 있습니다.

BareKeep는 어떻게 업데이트되나요?

BareKeep는 하루에 한 번, 그리고 사용자가 요청할 때 새 버전을 확인하며(매일 하는 확인은 설정에서 끌 수 있습니다), 확인하신 후 앱 안에서 설치합니다. 업데이트는 두 요금제 모두에서 무료입니다. 각 버전의 내역은 변경 내역에서 볼 수 있습니다.
