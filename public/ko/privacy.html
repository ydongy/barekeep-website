개인정보 처리방침

마지막 업데이트 · 2026년 10월

이 번역은 참고용입니다. 영어 버전과 내용이 다를 경우 영어 버전이 우선합니다.

BareKeep은 사용자나 사용 방식에 관한 어떠한 데이터도 수집하거나 업로드하지 않습니다. 원격 측정, 충돌 보고, 계정 시스템이 없습니다.

1. 수집하는 정보

Pro를 활성화, 확인 또는 비활성화할 때 BareKeep은 라이선스 키와 기기 이름표(Mac의 이름과 하드웨어 식별자에서 만든 짧은 코드)를 HTTPS로 Dodo Payments에 보냅니다. 그 외에는 당사나 결제 대행사에 아무것도 전송하지 않습니다.

BareKeep에는 계정, 분석 도구, 충돌 보고, 자체 서버가 없습니다. 당사로 보내는 그 밖의 요청은 아래에 설명하는 업데이트 확인뿐입니다.

2. 수집하지 않는 정보

BareKeep은 사용자의 저장소, 액세스 토큰, 미러 목록, 백업 서버, 앱 사용 방식을 수집하거나 받지 않습니다. 모든 것은 사용자의 Mac과 사용자가 선택한 서버에서 실행됩니다.

로그는 Mac에만 저장됩니다. 진단 정보를 내보내면 파일이 만들어지며, 이 파일은 사용자가 직접 보냅니다. 파일에서는 토큰이 제거됩니다. 다만 미러 목록(저장소 주소와 로컬 경로)은 포함되므로 공유하기 전에 확인하십시오.

3. 제3자 서비스

  • 사용자가 설정한 Git 서버: GitHub, GitLab, Gitea, Forgejo 또는 모든 https Git 서버이며, 시스템 git이 이곳에서 가져오고 이곳으로 푸시합니다. 토큰은 해당 토큰을 만든 호스트에만 https로 전송됩니다. 각 서버의 개인정보 처리방침이 적용됩니다.
  • 플랫폼 API: 자체 호스팅 인스턴스를 추가하면 BareKeep은 자격 증명 없이 서버 종류를 확인합니다(버전 엔드포인트만 요청합니다). 백업 대상의 연결 테스트와 저장소 자동 생성은 해당 플랫폼의 API를 호출합니다.
  • dl.barekeep.com: BareKeep의 새 버전을 확인하기 위해 하루에 한 번(매일 하는 확인을 끄면 제외), 그리고 사용자가 요청할 때 사용합니다. 요청에는 앱 이름과 버전, 업데이트 프레임워크의 버전, 사용자의 IP 주소가 포함되며 시스템 프로파일은 포함되지 않습니다. 업데이트는 사용자가 확인한 후에만 다운로드되며, Apple 서명과 BareKeep의 EdDSA 서명이 모두 검증된 경우에만 설치됩니다.
  • Dodo Payments: 결제 대행사이자 판매 대행자(merchant of record)입니다. 결제 시 Dodo는 Dodo의 개인정보 처리방침에 따라 이름, 이메일 주소, 청구 정보를 수집하고 청구서, 세금, 환불을 처리합니다. BareKeep는 결제 정보를 받지 않습니다.
  • 이 웹사이트: 정적 사이트이며 분석 도구와 쿠키가 없습니다. 웹사이트와 다운로드 파일은 Cloudflare가 제공하며, Cloudflare는 일반적인 접속 로그를 보관합니다.
  • 사용자의 브라우저: “…에서 열기”와 같은 링크는 시스템 브라우저에서 열립니다.

4. 데이터 저장

  • Pro 라이선스 키는 액세스 토큰과 마찬가지로 Mac의 키체인에 저장됩니다.
  • 액세스 토큰은 Mac의 키체인에만 저장되며, 소스 토큰과 백업 대상 토큰마다 항목이 하나씩 있습니다. 토큰은 파일이나 로그에 기록되지 않고 명령줄 인수나 환경 변수에도 나타나지 않으며, 파이프를 통해 git 하위 프로세스에 전달됩니다.
  • 미러 목록, 백업 대상, 실행 기록은 ~/Library/Application Support/BareKeep의 JSON 파일에 저장되며 토큰은 포함되지 않습니다. 로그는 ~/Library/Logs/BareKeep에 있으며, 기록되기 전에 비밀 정보가 제거됩니다.
  • 미러 저장소는 사용자가 지정한 폴더에 저장됩니다.

5. 사용자의 권리와 통제

설정 › 라이선스에서 언제든지 라이선스를 비활성화할 수 있습니다. 미러를 삭제하거나 백업 대상을 제거하면 해당 키체인 항목도 삭제됩니다. BareKeep을 삭제한 후에는 위의 폴더와 키체인 항목을 삭제할 수 있습니다.

개발자는 Dodo 대시보드에서 사용자의 구매 기록(이름, 이메일 주소, 결제 ID)을 볼 수 있으며, 지원과 환불 처리에만 사용합니다. 당사가 보유한 정보를 확인하거나 정정 또는 삭제를 요청하려면 support@barekeep.com로 이메일을 보내십시오. 30일 이내에 답변합니다. EU 또는 EEA에 거주하는 경우 GDPR이 보장하는 권리(관할 개인정보 보호 감독 기관에 불만을 제기할 권리 포함)도 가집니다.

6. 변경

이 방침이 변경되면 위의 날짜도 함께 변경됩니다.

BareKeep, 구매 또는 환불에 관한 문의는 support@barekeep.com로 이메일을 보내 주세요.
