Mac을 위한 비공개 코드 아카이브

오프라인이 되지 않는 나만의 코드 보관소.

BareKeep는 GitHub와 GitLab 저장소를 Mac에 미러링해 두고, 오프사이트 백업으로 나만의 Git 서버에 푸시할 수 있습니다.

Mac용 다운로드

macOS 26.0 이상 · 버전 1.0은 구매가 필요 없습니다

미러 No. 0042동기화됨

owner/repo

소스
github.com/owner/repo
보관 위치
~/Mirrors/repo.git
백업
git.example.com
마지막 실행
오늘 09:41, fast-forward

내 저장소, 내 기기.

  • 소스는 읽기 전용

    데이터는 소스, 이 Mac, 백업 순서로만 흐릅니다. BareKeep는 GitHub나 GitLab에 절대 쓰지 않습니다.

  • 토큰은 키체인에만

    액세스 토큰은 소스와 백업 대상마다 하나씩 Mac의 키체인에 저장되며, 파이프를 통해 git에 전달됩니다.

  • 수집하는 정보 없음

    원격 분석도, 충돌 보고서도, 계정도 없습니다. 미러와 실행 기록은 Mac에만 남습니다.

  • 진짜 Git 저장소

    모든 미러는 직접 고른 폴더에 만들어지는 완전한 bare 저장소입니다. 오프라인에서도 언제든 클론할 수 있습니다.

히스토리가 갈라지면 멈추고 물어봅니다.

백업은 fast-forward 푸시만 받습니다. 소스가 강제 푸시되면 BareKeep는 백업을 그대로 두고 해당 미러의 자동 동기화를 일시 중지한 뒤, 소스로 덮어쓸지 직접 결정하도록 합니다.

  1. 소스강제 푸시됨
  2. 이 Mac최신 상태
  3. 백업다른 커밋이 있어 보류

vercel/next.js 기록 불일치백업에 이 미러에 없는 커밋이 있어 BareKeep가 푸시하지 않았습니다. 백업을 확인하거나 소스로 덮어쓰세요.

모든 미러에는 표시등이 있습니다.

모양으로 상태를 알 수 있어, 색에 의존하지 않고도 읽을 수 있습니다.

  • 동기화됨

    소스와 최신 상태입니다.

  • 동기화 중

    실행이 진행 중입니다. 취소할 수 있습니다.

  • 기록 불일치

    소스 히스토리가 더 이상 백업과 일치하지 않습니다. 아무것도 덮어쓰지 않았습니다.

  • 실패

    마지막 실행이 실패했습니다. BareKeep가 이유를 쉬운 말로 알려 주고 백오프로 재시도합니다.

  • 일시 중지됨

    의도적으로 일시 중지되었습니다. 수동 동기화는 계속 작동합니다.

사용 중인 Git 호스트와 함께 작동합니다.

소스와 백업 대상은 같은 플랫폼 목록을 공유하므로, Gitea나 Forgejo 서버도 둘 다 될 수 있습니다.

  • GitHub
  • GitLab
  • Gitea
  • Forgejo
  • 자체 호스팅 인스턴스
  • 모든 https Git URL

세 단계로 설정합니다.

  1. 저장소 주소 붙여넣기

    BareKeep가 https 또는 ssh 주소에서 플랫폼, 소유자, 저장소 이름을 인식합니다.

  2. 폴더와 토큰 선택

    미러를 둘 Mac의 위치를 고르세요. 토큰은 바로 키체인에 저장됩니다.

  3. 백업 대상 추가 (선택 사항)

    BareKeep에 Gitea, Forgejo, GitLab 또는 GitHub를 지정하세요. 비공개 저장소를 대신 만들고, 동기화할 때마다 푸시합니다.

BareKeep 다운로드

BareKeep는 macOS 메뉴 막대 앱입니다. 미러는 백그라운드에서 실행되고, 메인 윈도우에서 모든 실행 내역을 볼 수 있습니다.

macOS 26.0 이상용입니다.

다운로드


확인하려면 다운로드한 파일에 대한 shasum -a 256의 출력과 비교하세요.

dmg를 열고 BareKeep를 응용 프로그램 폴더로 드래그하세요. BareKeep는 macOS에 포함된 Git을 사용하며, 이 Mac에 아직 없으면 명령어 라인 개발자 도구 설치를 안내합니다. 궁금한 점이 있으신가요? FAQ를 읽어 보세요.

가격

BareKeep에는 최대 3개의 미러를 관리하는 무료 플랜과, 제한 없는 일회성 구매 Pro가 있습니다. Pro 라이선스 하나로 모든 1.x 버전을 사용할 수 있습니다. 가격은 출시 시 이곳에 표시됩니다.

사용에는 이용약관이 적용됩니다.
