隐私政策

最后更新 · 2026 年 10 月

本页译文仅供参考；如与英文版本不一致，以英文版本为准。

BareKeep 不会收集或上传任何关于你或你使用情况的数据：没有遥测，没有崩溃报告，没有账号系统。

1. 我们收集什么

激活、验证或取消激活 Pro 时，BareKeep 会通过 HTTPS 向 Dodo Payments 发送授权码和一个设备标签（你的 Mac 名称加一段由硬件标识算出的短码）。除此之外不会向我们或支付服务商发送其他内容。

BareKeep 没有账号、没有统计分析、没有崩溃报告，也没有自己的服务器。它发给我们的另一个请求，是下文所述的更新检查。

2. 我们不收集什么

BareKeep 不会收集或接收你的仓库、访问令牌、镜像列表、备份服务器，也不会收集你如何使用这个应用。一切都在你的 Mac 和你自己选择的服务器上完成。

日志只保存在你的 Mac 上。导出诊断信息会生成一个由你自己发送的文件，其中的令牌已被去除。但文件包含镜像列表（仓库地址和本地路径），分享前请先检查。

3. 第三方服务

  • 你配置的 Git 服务器：GitHub、GitLab、Gitea、Forgejo 或任何 https Git 服务器，由系统自带的 git 从中拉取并向其推送。令牌只会通过 https 发送给创建它的那个主机。其自身的隐私政策适用。
  • 平台 API：添加自托管实例时，BareKeep 会在不带凭据的情况下探测服务器类型（只请求版本端点）。备份目标的连接测试和自动创建仓库会调用该平台的 API。
  • dl.barekeep.com：用于检查 BareKeep 是否有新版本，每天一次，除非你关闭每日检查；你主动要求时也会检查。请求包含应用名称和版本、更新框架的版本以及你的 IP 地址，不包含系统配置信息。更新只有在你确认后才会下载，并且只有 Apple 签名和 BareKeep 的 EdDSA 签名都验证通过才会安装。
  • Dodo Payments：我们的支付服务商和销售方（Merchant of Record）。结账时 Dodo 按其自身隐私政策收集你的姓名、邮箱和账单信息，并负责发票、税费和退款。BareKeep 不会收到你的支付信息。
  • 本网站：静态网站，没有统计分析，也不使用 Cookie。网站和下载文件由 Cloudflare 提供，Cloudflare 会保留标准的访问日志。
  • 你的浏览器：诸如“在……打开”之类的链接由系统浏览器打开。

4. 数据存储

  • 你的 Pro 授权码和访问令牌一样，保存在你 Mac 的钥匙串里。
  • 访问令牌只保存在你 Mac 的钥匙串里，每个来源令牌和每个备份目标令牌各占一条。它们不会写入文件或日志，也不会出现在命令行参数或环境变量中，而是通过管道交给 git 子进程。
  • 镜像列表、备份目标和运行历史是保存在 ~/Library/Application Support/BareKeep 的 JSON 文件，不含令牌。日志在 ~/Library/Logs/BareKeep，写入前已去除敏感信息。
  • 镜像仓库保存在你指定的文件夹中。

5. 你的权利与控制

你可以随时在“设置 › 许可”里取消激活授权码。删除镜像或移除备份目标时，对应的钥匙串条目也会被删除。卸载 BareKeep 后，你可以删除上述文件夹和钥匙串条目。

开发者可以在 Dodo 后台看到你的购买记录（姓名、邮箱、付款编号），仅用于提供支持和处理退款。如需了解我们持有你的哪些信息，或要求更正、删除，请发邮件到 support@barekeep.com，我们会在 30 天内回复。如果你位于欧盟或欧洲经济区，还享有 GDPR 赋予的权利，包括向当地数据保护机构投诉的权利。

6. 变更

本政策如有变更，上方的日期会随之更新。

对 BareKeep、购买或退款有疑问，请写信到 support@barekeep.com。
