你的 Mac 上的私人代码档案馆

一座永不离线的私人代码馆藏。

BareKeep 把 GitHub、GitLab 上的仓库持续镜像到你的 Mac，还能推送到你自己的 Git 服务器，做异地备份。

你的仓库，你的机器。

  • 对来源只读

    数据只按 来源、本机、备份 的方向流动。BareKeep 从不写回 GitHub 或 GitLab。

  • 令牌只在钥匙串

    访问令牌存在 Mac 的钥匙串里，每个来源、每个备份目标各一条，经管道交给 git。

  • 不收集任何数据

    没有遥测、没有崩溃上报、没有账号。镜像和运行记录都留在你的 Mac 上。

  • 就是真正的 Git 仓库

    每个镜像都是你指定目录里一个完整的 bare 仓库。随时可以从它克隆，断网也行。

历史分歧时，先停下来问你。

备份只接受快进推送。如果来源被强制推送，BareKeep 会保持备份原样，暂停这个镜像的自动同步，由你决定是否以来源为准覆盖。

  1. 来源已强制推送
  2. 这台 Mac已是最新
  3. 备份有其他提交，已拦下

vercel/next.js 内容分歧备份上有本机镜像没有的提交，为避免覆盖它们，BareKeep 没有推送。请检查备份，或以来源为准覆盖。

每个镜像都有一盏灯。

用形状表示状态，不必只靠颜色分辨。

  • 已同步

    与来源保持一致。

  • 同步中

    正在运行，可以随时取消。

  • 内容分歧

    来源的历史与备份不再一致。没有任何内容被覆盖。

  • 失败

    上一次运行失败。BareKeep 会用人话说明原因，并自动退避重试。

  • 已暂停

    主动暂停，仍可手动同步。

支持你在用的 Git 平台。

来源与备份目标共用同一份平台列表，Gitea、Forgejo 服务器既可以当来源，也可以当备份。

  • GitHub
  • GitLab
  • Gitea
  • Forgejo
  • 自建实例
  • 任意 https Git 地址

三步开始。

  1. 粘贴仓库地址

    BareKeep 会从 https 或 ssh 地址里认出平台、所有者和仓库名。

  2. 选择目录和令牌

    选好镜像存放在 Mac 上的位置。令牌直接进钥匙串。

  3. 添加备份目标（可选）

    指向你的 Gitea、Forgejo、GitLab 或 GitHub。BareKeep 会自动建私有库，并在每次同步后推送。

下载 BareKeep

BareKeep 是 macOS 菜单栏应用。镜像在后台运行，主窗口可以查看每一次运行。

需要 macOS 26.0 或更高版本。

下载


如需校验，请把它与下载文件的 shasum -a 256 输出对比。

打开 dmg，把 BareKeep 拖进「应用程序」。BareKeep 使用 macOS 自带的 Git；如果这台 Mac 还没有，BareKeep 会引导你安装「命令行开发者工具」。有疑问？看看常见问题。

定价

BareKeep 有免费版，最多管理 3 个镜像；还有 Pro，一次买断，没有限制。一个 Pro 授权码覆盖 1.x 的所有版本。价格会在发布时显示在这里。
