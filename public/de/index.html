Ein privates Code-Archiv für Ihren Mac

Ein privater Code-Tresor, der nie offline geht.

BareKeep hält Ihre GitHub- und GitLab-Repositories als Spiegel auf Ihrem Mac und kann sie als externes Backup auf Ihren eigenen Git-Server pushen.

Für Mac laden

macOS 26.0 oder neuer · Version 1.0 erfordert keinen Kauf

Ihre Repositories, Ihre Rechner.

  • Nur lesend auf der Quelle

    Daten fließen nur von der Quelle auf diesen Mac und dann ins Backup. BareKeep schreibt nie zurück zu GitHub oder GitLab.

  • Tokens bleiben im Schlüsselbund

    Zugriffstokens liegen im Schlüsselbund Ihres Macs, eines pro Quelle und pro Backup-Ziel, und werden über eine Pipe an git übergeben.

  • Es wird nichts erfasst

    Keine Telemetrie, keine Absturzberichte, kein Konto. Spiegel und Laufverlauf bleiben auf Ihrem Mac.

  • Ein echtes Git-Repository

    Jeder Spiegel ist ein vollständiges Bare-Repository in einem Ordner Ihrer Wahl. Sie können jederzeit davon klonen, auch offline.

Wenn Verläufe auseinanderlaufen, hält BareKeep an und fragt nach.

Das Backup akzeptiert nur Fast-Forward-Pushes. Wurde die Quelle per Force-Push überschrieben, belässt BareKeep das Backup unverändert, pausiert die automatische Synchronisierung dieses Spiegels und überlässt Ihnen die Entscheidung, ob es von der Quelle überschrieben werden soll.

Jeder Spiegel hat eine Lampe.

Die Form zeigt den Zustand an, sodass Sie ihn ohne Farben erkennen können.

  • Synchronisiert

    Auf dem Stand der Quelle.

  • Synchronisierung läuft

    Ein Lauf ist im Gange. Sie können ihn abbrechen.

  • Abweichend

    Der Verlauf der Quelle stimmt nicht mehr mit dem Backup überein. Es wurde nichts überschrieben.

  • Fehlgeschlagen

    Der letzte Lauf ist fehlgeschlagen. BareKeep nennt den Grund in klaren Worten und versucht es mit Backoff erneut.

  • Pausiert

    Absichtlich pausiert. Manuelles Synchronisieren funktioniert weiterhin.

Funktioniert mit den Git-Hosts, die Sie nutzen.

Quellen und Backup-Ziele teilen sich dieselbe Plattformliste, daher kann ein Gitea- oder Forgejo-Server beides sein.

  • GitHub
  • GitLab
  • Gitea
  • Forgejo
  • Selbst gehostete Instanzen
  • Jede https-Git-URL

In drei Schritten eingerichtet.

  1. Repository-Adresse einfügen

    BareKeep erkennt Plattform sowie Eigentümer und Repository-Namen anhand einer https- oder ssh-Adresse.

  2. Ordner und Token wählen

    Legen Sie fest, wo der Spiegel auf Ihrem Mac liegt. Das Token landet direkt im Schlüsselbund.

  3. Backup-Ziel hinzufügen (optional)

    Verweisen Sie BareKeep auf Ihr Gitea, Forgejo, GitLab oder GitHub. Es legt private Repositories für Sie an und pusht nach jeder Synchronisierung.

BareKeep laden

BareKeep ist eine Menüleisten-App für macOS. Spiegel laufen im Hintergrund, und das Hauptfenster zeigt jeden Lauf.

Für macOS 26.0 oder neuer.

Download


Zum Prüfen vergleichen Sie sie mit der Ausgabe von shasum -a 256 für die geladene Datei.

Öffnen Sie die dmg und ziehen Sie BareKeep in den Ordner „Programme“. BareKeep nutzt das Git, das mit macOS geliefert wird; falls dieser Mac es noch nicht hat, bietet BareKeep an, die Command Line Developer Tools zu installieren. Fragen? Lesen Sie die FAQ.
