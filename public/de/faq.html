Häufig gestellte Fragen

Ihre Antwort fehlt? BareKeep erklärt Fehler in klaren Worten im Laufprotokoll und auf der Statuskarte des Spiegels. Öffnen Sie zuerst den Spiegel.

Grundlagen

Was ist BareKeep?

Eine Menüleisten-App für macOS, die Spiegel Ihrer GitHub-, GitLab-, Gitea- und Forgejo-Repositories auf Ihrem Mac hält und sie als externes Backup auf Ihren eigenen Git-Server pushen kann. Jeder Spiegel ist ein vollständiges Git-Repository, von dem Sie jederzeit klonen können.

Was brauche ich?

Einen Mac mit macOS 26.0 oder neuer und Git. BareKeep nutzt das Git, das mit macOS geliefert wird; fehlen die Command Line Developer Tools, zeigt BareKeep eine Seite, die sie für Sie installiert (etwa 1 GB, von Apple). Spiegel und Einstellungen bleiben unberührt, solange Git fehlt, und die Synchronisierung wird nach der Installation fortgesetzt.

Muss ich für BareKeep bezahlen?

BareKeep hat eine kostenlose Version, die bis zu 3 Spiegel verwaltet, und Pro, einen Einmalkauf (kein Abonnement) ohne diese Begrenzung. Eine Pro-Lizenz gilt für alle Versionen 1.x. Siehe Preise.

Kann ich BareKeep auf mehr als einem Mac nutzen?

Ja. Die kostenlose Version läuft auf jedem Mac, den Sie besitzen oder kontrollieren. Ein Pro-Lizenzschlüssel kann auf 2 Ihrer Macs gleichzeitig aktiv sein. Um ihn auf einem weiteren zu nutzen, deaktivieren Sie ihn zuerst unter Einstellungen › Lizenz auf einem der beiden.

Kann ich mein Geld zurückbekommen?

Ja, innerhalb von 14 Tagen nach dem Kauf von Pro, ohne Angabe eines Grundes. Die Regeln stehen in der Erstattungsrichtlinie.

Was passiert mit meinen Spiegeln, wenn meine Lizenz nicht mehr funktioniert?

Nichts, was Sie bereits gespiegelt oder gesichert haben, wird gelöscht, und die Spiegel auf Ihrer Festplatte bleiben lesbar. BareKeep kehrt zur kostenlosen Version zurück: Die ersten 3 Spiegel werden weiter synchronisiert, die übrigen bleiben, wo sie sind, werden aber nicht synchronisiert, bis Sie upgraden.

Verändert BareKeep meine Repositories auf GitHub oder GitLab?

Nein. Daten fließen nur von der Quelle auf diesen Mac und dann ins Backup. BareKeep pusht nie zur Quelle.

Welche Git-Hosts funktionieren?

GitHub, GitLab, Gitea, Forgejo (einschließlich codeberg.org), selbst gehostete Instanzen der letzten drei sowie jede https-Git-URL. Fügen Sie eine selbst gehostete Instanz zuerst unter Einstellungen › Plattformen hinzu; danach kann sie Quelle oder Backup-Ziel sein.

Wie bekomme ich Hilfe?

Beginnen Sie mit dem Protokoll und der Statuskarte des Spiegels, bei dem das Problem auftritt: Sie erklären Fehler in einfachen Worten. Wenn das nicht hilft, schreiben Sie an support@barekeep.com und teilen Sie mit, was die Statuskarte anzeigt. Senden Sie niemals ein Zugriffstoken.

Synchronisierung und Backups

Wie funktioniert die Synchronisierung?

Jetzt synchronisieren führt einen Spiegel sofort aus; ein Zeitplan führt sie automatisch aus. Fehlgeschlagene Läufe werden mit Backoff wiederholt, und das Laufprotokoll sowie die Ausgabe jedes Laufs finden Sie auf der Detailseite des Spiegels. Synchronisierung pausieren stoppt automatische Läufe; manuelles Synchronisieren funktioniert weiterhin.

Wie funktioniert das Backup?

Fügen Sie ein oder mehrere Backup-Ziele hinzu (Gitea, Forgejo, GitLab oder GitHub) und wählen Sie pro Spiegel, auf welche er pusht. Wo die Plattform eine API hat, legt BareKeep das private Repository für Sie an. Das Backup ist optional: Ohne Ziel bleibt der Spiegel auf diesem Mac.

Was bedeutet „Abweichend“?

Das Backup enthält Commits, die dieser Spiegel nicht hat, zum Beispiel nach einem Force-Push auf die Quelle. Um sie nicht zu überschreiben, pusht BareKeep nicht und pausiert die automatische Synchronisierung dieses Spiegels. Prüfen Sie das Backup oder wählen Sie Aus Quelle überschreiben …, um dessen Branches und Tags auf den Stand der Quelle zurückzusetzen. Commits, die nur im Backup existieren, werden danach nicht mehr referenziert; kopieren Sie daher zuerst den lokalen Ordner, wenn Sie sie behalten möchten.

Datenschutz und Sicherheit

Wo wird mein Zugriffstoken gespeichert?

Nur im Schlüsselbund Ihres Macs, ein Eintrag pro Quelle und pro Backup-Ziel. Es wird nicht in Dateien oder Protokolle geschrieben und erscheint weder in Befehlszeilen noch in Umgebungsvariablen; es wird über eine Pipe an git übergeben.

Erfasst BareKeep Daten?

Keine Telemetrie, keine Absturzberichte, kein Konto. BareKeep sendet nur die Suche nach Updates und, wenn Sie Pro kaufen, Ihren Lizenzschlüssel und eine Gerätebezeichnung an den Zahlungsdienstleister. Die Datenschutzerklärung listet jede Adresse auf, mit der sich BareKeep verbindet.

Wie aktualisiert sich BareKeep?

BareKeep sucht einmal täglich und auf Ihre Anforderung nach neuen Versionen (die tägliche Suche ist in den Einstellungen abschaltbar) und installiert sie nach Ihrer Bestätigung in der App. Updates sind bei beiden Tarifen kostenlos. Den Verlauf jeder Version finden Sie im Changelog.
