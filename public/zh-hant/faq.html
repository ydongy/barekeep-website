常見問題

找不到答案嗎？BareKeep 會在執行記錄與鏡像的狀態卡片中，用白話說明失敗原因。請先打開該鏡像看看。

基本問題

BareKeep 是什麼？

這是一款 macOS 選單列 App，會把你在 GitHub、GitLab、Gitea 與 Forgejo 上的儲存庫持續鏡像到 Mac，還能推送到你自己的 Git 伺服器，作為異地備份。每個鏡像都是完整的 Git 儲存庫，隨時可以複製。

需要準備什麼？

一台搭載 macOS 26.0 或以上版本的 Mac，以及 Git。BareKeep 使用 macOS 內建的 Git；若缺少「命令列開發者工具」，BareKeep 會顯示頁面引導你安裝（約 1 GB，由 Apple 提供）。缺少 Git 期間，鏡像與設定都不受影響，安裝完成後會自動恢復同步。

BareKeep 需要付費嗎？

BareKeep 有可管理最多 3 個鏡像的免費版，以及沒有此限制、一次買斷（非訂閱）的 Pro。一組 Pro 授權碼涵蓋 1.x 的所有版本。詳見價格。

我可以在多台 Mac 上使用 BareKeep 嗎？

可以。免費版可用在你擁有或控制的每一台 Mac 上。一組 Pro 授權碼可以同時在你的 2 台 Mac 上啟用；要換到另一台 Mac，請先在其中一台的「設定 › 授權」中停用。

可以退款嗎？

可以，購買 Pro 後 14 天內都可以申請，不需要說明理由。規則請見退款政策。

如果我的授權碼失效，我的鏡像會怎樣？

你已經鏡像或備份的內容都不會被刪除，磁碟上的鏡像仍可讀取。BareKeep 會回到免費版：前 3 個鏡像會繼續同步，其餘的鏡像會留在原處，但在你升級之前不會同步。

BareKeep 會更動我在 GitHub 或 GitLab 上的儲存庫嗎？

不會。資料只依「來源、這台 Mac、備份」的方向流動，BareKeep 絕不會推送到來源。

支援哪些 Git 平台？

GitHub、GitLab、Gitea、Forgejo（含 codeberg.org）、後三者自行架設的站台，以及任何 https Git 網址。自行架設的站台請先在 設定 › 平台 中新增，之後即可當作來源或備份目標。

如何取得協助？

請先查看出問題的鏡像的執行記錄和狀態卡片：它們會用簡單的文字說明失敗原因。如果仍無法解決，請寄信到 support@barekeep.com，並說明狀態卡片顯示的內容。切勿寄送存取權杖。

同步與備份

同步是如何運作的？

立即同步 會立即執行一個鏡像；排程則會自動執行。失敗的執行會以退避方式重試，執行記錄與每次執行的輸出都在鏡像的詳細資訊頁面。暫停同步 會停止自動執行，仍可手動同步。

備份是如何運作的？

新增一個或多個備份目標（Gitea、Forgejo、GitLab 或 GitHub），並為每個鏡像選擇要推送到哪些目標。平台提供 API 時，BareKeep 會替你建立私人儲存庫。備份是選用的：未設定目標時，鏡像只會保留在這台 Mac 上。

「內容分歧」是什麼意思？

備份中有此鏡像沒有的提交，例如來源遭到強制推送之後。為避免覆寫這些提交，BareKeep 不會推送，並暫停該鏡像的自動同步。請檢查備份，或選擇 以來源為準覆寫…，將備份的分支與標籤重設為與來源一致。僅存在於備份中的提交將不再被參照，若想保留，請先拷貝本機資料夾。

隱私與安全

我的存取權杖存放在哪裡？

只存放在 Mac 的鑰匙圈中，每個來源、每個備份目標各一筆。不會寫入檔案或記錄，也不會出現在指令列或環境變數中，而是透過管線交給 git。

BareKeep 會蒐集資料嗎？

沒有遙測、沒有當機回報、沒有帳戶。BareKeep 傳送的資料只有更新檢查，以及（如果你購買 Pro）傳送給付款服務商的授權碼和裝置標籤。隱私權政策列出了 BareKeep 連線的每一個位址。

BareKeep 如何更新？

BareKeep 每天檢查一次新版本，你主動要求時也會檢查（可在設定中關閉每日檢查），經你確認後在 App 內安裝。兩種方案的更新皆為免費。每個版本的更新內容請見更新日誌。
