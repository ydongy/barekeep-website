隱私權政策

最後更新 · 2026 年 10 月

本頁譯文僅供參考；如與英文版本不一致，以英文版本為準。

BareKeep 不會收集或上傳任何關於你或你使用方式的資料：沒有遙測、沒有當機回報、沒有帳戶系統。

1. 我們收集什麼

啟用、驗證或停用 Pro 時，BareKeep 會透過 HTTPS 向 Dodo Payments 傳送授權碼和一個裝置標籤（你的 Mac 名稱加上一段由硬體識別碼算出的短碼）。除此之外，不會向我們或付款服務商傳送其他內容。

BareKeep 沒有帳戶、沒有分析統計、沒有當機回報，也沒有自己的伺服器。它對我們發出的另一項請求，是下方所述的更新檢查。

2. 我們不收集什麼

BareKeep 不會收集或接收你的儲存庫、你的存取權杖、你的鏡像清單、你的備份伺服器，也不會收集你如何使用這個 App。一切都在你的 Mac 和你自己選擇的伺服器上完成。

記錄檔只保存在你的 Mac 上。匯出診斷資訊會產生一個由你自行傳送的檔案，其中的權杖已移除，但包含鏡像清單（儲存庫位址和本機路徑），分享前請先檢查。

3. 第三方服務

  • 你設定的 Git 伺服器：GitHub、GitLab、Gitea、Forgejo 或任何 https Git 伺服器，由系統的 git 從中擷取並推送。權杖只會透過 https 傳送給建立它的主機。這些伺服器適用其自身的隱私權政策。
  • 平台 API：新增自架站台時，BareKeep 會在不帶憑證的情況下探測伺服器類型（只請求版本端點）。備份目標的連線測試和自動建立儲存庫，會呼叫該平台的 API。
  • dl.barekeep.com：用於檢查 BareKeep 是否有新版本，每天一次，除非你關閉每日檢查；你主動要求時也會檢查。請求包含 App 名稱與版本、更新框架的版本以及你的 IP 位址，不包含系統設定檔資訊。更新只會在你確認後下載，且只有在 Apple 簽章和 BareKeep 的 EdDSA 簽章都驗證通過時才會安裝。
  • Dodo Payments：我們的付款服務商和銷售方（Merchant of Record）。結帳時，Dodo 依其自身的隱私權政策收集你的姓名、電子郵件地址和帳單資料，並負責發票、稅款和退款。BareKeep 不會收到你的付款資料。
  • 本網站：靜態網站，沒有分析統計，也不使用 Cookie。網站和下載檔案由 Cloudflare 提供，Cloudflare 會保留標準的存取記錄。
  • 你的瀏覽器：像「在……開啟」這樣的連結，由系統瀏覽器開啟。

4. 資料儲存

  • 你的 Pro 授權碼和存取權杖一樣，保存在你 Mac 的鑰匙圈中。
  • 存取權杖只保存在你 Mac 的鑰匙圈中，每個來源權杖和每個備份目標權杖各一筆項目。權杖不會寫入檔案或記錄檔，也不會出現在命令列引數或環境變數中，而是透過管線交給 git 子程序。
  • 鏡像清單、備份目標和執行歷程是 ~/Library/Application Support/BareKeep 中的 JSON 檔案，不含權杖。記錄檔在 ~/Library/Logs/BareKeep，寫入前已移除機密資訊。
  • 鏡像儲存庫保存在你指定的資料夾中。

5. 你的權利與控制

你可以隨時在「設定 › 授權」中停用授權碼。刪除鏡像或移除備份目標時，會一併刪除它的鑰匙圈項目。解除安裝 BareKeep 後，你可以刪除上述資料夾和鑰匙圈項目。

開發者可以在 Dodo 後台看到你的購買紀錄（姓名、電子郵件地址、付款編號），僅用於提供支援和處理退款。如需了解我們持有你的哪些資料，或要求更正、刪除，請寄信到 support@barekeep.com，我們會在 30 天內回覆。如果你位於歐盟或歐洲經濟區，還享有 GDPR 賦予的權利，包括向當地資料保護機關申訴的權利。

6. 變更

本政策如有變更，上方的日期會隨之更新。

對 BareKeep、購買或退款有疑問，請寫信到 support@barekeep.com。
