你的 Mac 上的私人程式碼檔案庫

一座永不離線的私人程式碼典藏庫。

BareKeep 會把你在 GitHub、GitLab 上的儲存庫持續鏡像到 Mac，還能推送到你自己的 Git 伺服器，作為異地備份。

下載 Mac 版

需要 macOS 26.0 或以上版本 · 1.0 版無需購買

你的儲存庫，你的機器。

  • 對來源唯讀

    資料只依「來源、這台 Mac、備份」的方向流動。BareKeep 絕不寫回 GitHub 或 GitLab。

  • 權杖只放在鑰匙圈

    存取權杖存放在 Mac 的鑰匙圈中，每個來源、每個備份目標各一筆，並透過管線交給 git。

  • 不蒐集任何資料

    沒有遙測、沒有當機回報、不需要帳號。鏡像與執行記錄都留在你的 Mac 上。

  • 貨真價實的 Git 儲存庫

    每個鏡像都是你所選資料夾中的完整 bare 儲存庫。隨時都能從中複製，離線也行。

歷史出現分歧時，先停下來問你。

備份只接受快轉推送。若來源遭到強制推送，BareKeep 會維持備份原狀，暫停該鏡像的自動同步，由你決定是否以來源覆寫。

  1. 來源已強制推送
  2. 這台 Mac已是最新
  3. 備份有其他提交，已攔下

vercel/next.js 內容分歧備份中有此鏡像沒有的提交，因此 BareKeep 沒有推送。請檢查備份，或以來源覆寫。

每個鏡像都有一盞燈。

以形狀表示狀態，不必只靠顏色判讀。

  • 已同步

    與來源保持一致。

  • 同步中

    正在執行，可隨時取消。

  • 內容分歧

    來源的歷史與備份不再一致。沒有任何內容被覆寫。

  • 失敗

    上次執行失敗。BareKeep 會用白話說明原因，並以退避方式自動重試。

  • 已暫停

    刻意暫停，仍可手動同步。

支援你慣用的 Git 平台。

來源與備份目標共用同一份平台清單，Gitea 或 Forgejo 伺服器既能當來源，也能當備份。

  • GitHub
  • GitLab
  • Gitea
  • Forgejo
  • 自行架設的站台
  • 任何 https Git 網址

三步驟完成設定。

  1. 貼上儲存庫網址

    BareKeep 能從 https 或 ssh 網址辨識出平台、擁有者與儲存庫名稱。

  2. 選擇資料夾與權杖

    選好鏡像在 Mac 上的存放位置。權杖會直接存入鑰匙圈。

  3. 新增備份目標（選用）

    指向你的 Gitea、Forgejo、GitLab 或 GitHub。BareKeep 會替你建立私人儲存庫，並在每次同步後推送。

下載 BareKeep

BareKeep 是 macOS 選單列 App。鏡像在背景執行，主視窗可查看每一次執行。

需要 macOS 26.0 或以上版本。

下載


如需驗證，請將它與下載檔案的 shasum -a 256 輸出結果比對。

打開 dmg，將 BareKeep 拖移到「應用程式」。BareKeep 使用 macOS 內建的 Git；若這台 Mac 尚未安裝，BareKeep 會引導你安裝「命令列開發者工具」。有疑問嗎？請參閱常見問題。
