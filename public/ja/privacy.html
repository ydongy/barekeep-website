プライバシーポリシー

最終更新 · 2026年10月

この翻訳は参考用です。英語版と内容が異なる場合は、英語版が優先されます。

BareKeep は、お客様に関する情報や使用状況を収集もアップロードもしません。テレメトリなし、クラッシュレポートなし、アカウントシステムなし。

1. 収集する情報

Pro を有効化、確認、または無効化するとき、BareKeep はライセンスキーとデバイス名（お使いの Mac の名前と、ハードウェア識別子から作られた短いコード）を、HTTPS で Dodo Payments に送信します。当方にも決済事業者にも、これ以外の情報は送信されません。

BareKeep にはアカウントも、分析機能も、クラッシュレポートも、独自のサーバーもありません。当方に対して行うその他のリクエストは、下記の更新確認のみです。

2. 収集しない情報

BareKeep は、お客様のリポジトリ、アクセストークン、ミラー一覧、バックアップサーバー、アプリの使い方を、収集することも受け取ることもありません。すべてお使いの Mac 上と、お客様が選んだサーバー上で動作します。

ログはお使いの Mac に残ります。診断情報を書き出すと、ご自身で送信するファイルが作られます。トークンは取り除かれます。ただし、ミラー一覧（リポジトリのアドレスとローカルパス）は含まれるため、共有する前にご確認ください。

3. 第三者のサービス

  • お客様が設定した Git サーバー：GitHub、GitLab、Gitea、Forgejo、またはその他の https Git サーバーです。システムの git がここから取得し、ここへプッシュします。トークンは、作成した対象のホストにのみ、https で送信されます。各サービスのプライバシーポリシーが適用されます。
  • プラットフォーム API：セルフホストのインスタンスを追加するとき、BareKeep は認証情報なしでサーバーの種類を調べます（リクエストするのはバージョンのエンドポイントのみです）。バックアップ先の接続テストとリポジトリの自動作成では、そのプラットフォームの API を呼び出します。
  • dl.barekeep.com：BareKeep の新しいバージョンを確認するために使います。毎日の確認をオフにしない限り 1 日に 1 回、またお客様が求めたときにも確認します。リクエストには、アプリ名とバージョン、アップデートフレームワークのバージョン、お客様の IP アドレスが含まれ、システムプロファイルは含まれません。アップデートは、お客様が確認した後にのみダウンロードされ、Apple の署名と BareKeep の EdDSA 署名の両方が検証できた場合にのみインストールされます。
  • Dodo Payments：当方の決済事業者であり、販売代行者（merchant of record）です。決済時に、Dodo は氏名、メールアドレス、請求先情報を自社のプライバシーポリシーに基づいて収集し、請求書、税金、返金を処理します。BareKeep が決済情報を受け取ることはありません。
  • このウェブサイト：静的サイトで、分析機能も Cookie もありません。サイトとダウンロードは Cloudflare から配信され、Cloudflare は標準的なアクセスログを保持します。
  • お使いのブラウザ：「… で開く」などのリンクは、システムのブラウザで開かれます。

4. データの保存

  • Pro のライセンスキーは、アクセストークンと同様に、お使いの Mac のキーチェーンに保存されます。
  • アクセストークンは、お使いの Mac のキーチェーンにのみ保存されます。ソースのトークンごと、バックアップ先のトークンごとに 1 件です。ファイルやログには書き込まれず、コマンドライン引数や環境変数にも現れません。git のサブプロセスには、パイプ経由で渡されます。
  • ミラー一覧、バックアップ先、実行履歴は ~/Library/Application Support/BareKeep の JSON ファイルに保存され、トークンは含まれません。ログは ~/Library/Logs/BareKeep にあり、書き込む前に機密情報が取り除かれます。
  • ミラーのリポジトリは、お客様が指定したフォルダに保存されます。

5. お客様の権利と管理

設定 › ライセンス から、いつでもライセンスを無効化できます。ミラーを削除するか、バックアップ先を取り除くと、そのキーチェーンの項目も削除されます。BareKeep をアンインストールした後は、上記のフォルダとキーチェーンの項目を削除できます。

開発者は、Dodo のダッシュボードで購入記録（氏名、メールアドレス、支払い ID）を確認できます。目的は、サポートの提供と返金の処理に限ります。当方が保有するお客様の情報について確認、訂正、削除を希望する場合は、support@barekeep.com にメールでご連絡ください。30 日以内に返信します。EU または EEA にお住まいの場合は、所在地のデータ保護当局に苦情を申し立てる権利を含め、GDPR が定める権利もあります。
