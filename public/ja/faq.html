よくある質問

お探しの答えが見つかりませんか? BareKeep は失敗の理由を、実行ログとミラーのステータスカードでわかりやすい言葉で説明します。まずミラーを開いてください。

基本

BareKeep とは何ですか?

GitHub、GitLab、Gitea、Forgejo のリポジトリのミラーを Mac に保持し、オフサイトバックアップとして自分の Git サーバにプッシュできる macOS のメニューバーアプリです。各ミラーは、いつでもクローンできる完全な Git リポジトリです。

必要なものは何ですか?

macOS 26.0 以降の Mac と Git が必要です。BareKeep は macOS に付属の Git を使います。Command Line Developer Tools がない場合は、インストールするためのページが表示されます (Apple から約 1 GB)。Git がない間もミラーと設定は変更されず、インストール後に同期が再開されます。

BareKeep は有料ですか？

BareKeep には、最大 3 つのミラーを管理できる無料版と、こうした制限のない買い切り（サブスクリプションではありません）の Pro があります。Pro のライセンス 1 つで、1.x のすべてのバージョンを使えます。価格をご覧ください。

BareKeep を複数の Mac で使えますか？

はい。無料版は、ご自身が所有または管理するすべての Mac で使えます。Pro のライセンスキーは、ご自身の Mac 2 台で同時に有効にできます。別の Mac で使うには、先に 2 台のどちらかで 設定 › ライセンス から無効化してください。

返金してもらえますか？

はい、Pro の購入から 14 日以内であれば、理由を問わず可能です。規則は返金ポリシーに記載しています。

ライセンスが使えなくなった場合、ミラーはどうなりますか？

すでにミラーやバックアップしたものが削除されることはなく、ディスク上のミラーも引き続き読み取れます。BareKeep は無料版に戻ります。最初の 3 つのミラーは同期を続け、それ以外のミラーはそのまま残りますが、アップグレードするまで同期されません。

BareKeep は GitHub や GitLab 上の自分のリポジトリを変更しますか?

いいえ。データはソース、この Mac、バックアップの順にのみ流れます。BareKeep がソースにプッシュすることはありません。

どの Git ホストに対応していますか?

GitHub、GitLab、Gitea、Forgejo (codeberg.org を含む)、後者 3 つのセルフホストインスタンス、そして任意の https Git URL です。セルフホストのインスタンスは、まず 設定 › プラットフォーム で追加してください。追加後はソースにもバックアップ先にも使えます。

サポートを受けるには？

まず、問題のあるミラーの実行ログとステータスカードをご確認ください。失敗の理由が分かりやすい言葉で説明されています。解決しない場合は、ステータスカードの表示内容を添えて support@barekeep.com にメールでご連絡ください。アクセストークンは絶対に送らないでください。

同期とバックアップ

同期はどのように動きますか?

「今すぐ同期」はミラーをすぐに実行し、スケジュールは自動で実行します。失敗した実行はバックオフしながら再試行され、実行ログと各実行の出力はミラーの詳細ページで確認できます。「同期を一時停止」は自動実行を止めますが、手動同期は引き続き使えます。

バックアップはどのように動きますか?

バックアップ先 (Gitea、Forgejo、GitLab、GitHub) を 1 つ以上追加し、ミラーごとにプッシュ先を選びます。プラットフォームに API がある場合は、BareKeep がプライベートリポジトリを作成します。バックアップは任意です。バックアップ先がなければ、ミラーはこの Mac に残ります。

「履歴の不一致」とはどういう意味ですか?

ソースが force-push された場合などに、バックアップにこのミラーにないコミットがある状態です。それらを上書きしないよう、BareKeep はプッシュせず、そのミラーの自動同期を一時停止します。バックアップを確認するか、ソースで上書き… を選んで、ブランチとタグをソースに合わせてリセットしてください。バックアップにしかないコミットは参照されなくなるため、残したい場合は先にローカルのフォルダをコピーしてください。

プライバシーとセキュリティ

アクセストークンはどこに保存されますか?

Mac のキーチェーンにのみ、ソースごと、バックアップ先ごとに 1 項目ずつ保存されます。ファイルやログには書き込まれず、コマンドラインや環境変数にも現れません。パイプ経由で git に渡されます。

BareKeep はデータを収集しますか?

テレメトリ、クラッシュレポート、アカウントはありません。BareKeep が送信するデータは、更新確認と、Pro を購入した場合にライセンスキーとデバイス名を決済事業者へ送るものだけです。BareKeep が接続するすべてのアドレスは、プライバシーポリシーに記載しています。

BareKeep はどのようにアップデートしますか?

BareKeep は 1 日に 1 回、またお客様が求めたときにも新しいバージョンを確認し (毎日の確認は設定でオフにできます)、確認後にアプリ内でインストールします。アップデートは両方のプランで無料です。各バージョンの履歴は更新履歴にあります。
