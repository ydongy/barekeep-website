Mac のためのプライベートなコードアーカイブ

オフラインにならない、プライベートなコードの金庫。

BareKeep は GitHub と GitLab のリポジトリを Mac にミラーし続け、オフサイトバックアップとして自分の Git サーバにプッシュできます。

あなたのリポジトリ、あなたのマシンで。

  • ソース側は読み取り専用

    データはソース、この Mac、バックアップの順にのみ流れます。BareKeep が GitHub や GitLab に書き戻すことはありません。

  • トークンはキーチェーンに保管

    アクセストークンは Mac のキーチェーンに、ソースごと、バックアップ先ごとに保管され、パイプ経由で git に渡されます。

  • 何も収集しません

    テレメトリもクラッシュレポートもアカウントもありません。ミラーと実行履歴は Mac の中にだけ残ります。

  • 本物の Git リポジトリ

    すべてのミラーは、選んだフォルダにある完全なベアリポジトリです。オフラインでもいつでもクローンできます。

履歴が分岐したら、止まって確認します。

すべてのミラーにランプがあります。

形で状態がわかるので、色に頼らずに読み取れます。

  • 同期済み

    ソースと同じ状態です。

  • 同期中

    実行中です。キャンセルできます。

  • 履歴の不一致

    ソースの履歴がバックアップと一致しなくなりました。何も上書きされていません。

  • 失敗

    前回の実行に失敗しました。BareKeep が理由をわかりやすい言葉で伝え、バックオフしながら再試行します。

  • 一時停止中

    意図的に停止しています。手動同期は引き続き使えます。

お使いの Git ホストに対応。

ソースとバックアップ先は同じプラットフォーム一覧を共有するので、Gitea や Forgejo のサーバはどちらにもなれます。

  • GitHub
  • GitLab
  • Gitea
  • Forgejo
  • セルフホストのインスタンス
  • 任意の https Git URL

3 ステップで設定。

  1. リポジトリのアドレスを貼り付け

    https または ssh のアドレスから、BareKeep がプラットフォーム、オーナー、リポジトリ名を認識します。

  2. フォルダとトークンを選択

    ミラーを置く Mac 上の場所を選びます。トークンはそのままキーチェーンに保存されます。

  3. バックアップ先を追加 (任意)

    Gitea、Forgejo、GitLab、GitHub のいずれかを指定します。プライベートリポジトリは BareKeep が作成し、同期のたびにプッシュします。

BareKeep をダウンロード

BareKeep は macOS のメニューバーアプリです。ミラーはバックグラウンドで実行され、メインウインドウですべての実行を確認できます。

macOS 26.0 以降に対応。

ダウンロード


確認するには、ダウンロードしたファイルに対する shasum -a 256 の出力と比較してください。
