Une archive de code privée pour votre Mac

Un coffre-fort privé pour votre code, toujours disponible.

BareKeep garde vos dépôts GitHub et GitLab en miroir sur votre Mac, et peut les envoyer vers votre propre serveur Git comme sauvegarde externe.

Vos dépôts, vos machines.

  • Lecture seule sur la source

    Les données circulent dans un seul sens : source, puis ce Mac, puis sauvegarde. BareKeep n’écrit jamais sur GitHub ni sur GitLab.

  • Les jetons restent dans le trousseau

    Les jetons d’accès sont conservés dans le trousseau d’accès de votre Mac, un par source et par cible de sauvegarde, et sont transmis à git par un tube.

  • Aucune collecte

    Ni télémétrie, ni rapports d’incident, ni compte. Les miroirs et l’historique des exécutions restent sur votre Mac.

  • Un vrai dépôt Git

    Chaque miroir est un dépôt bare complet, dans un dossier de votre choix. Clonez-le à tout moment, même hors connexion.

Quand les historiques divergent, BareKeep s’arrête et vous demande.

La sauvegarde n’accepte que les envois en fast-forward. Si la source a subi un force-push, BareKeep laisse la sauvegarde intacte, suspend la synchronisation automatique de ce miroir et vous laisse décider de l’écraser ou non à partir de la source.

Chaque miroir a son voyant.

La forme indique l’état, vous pouvez donc le lire sans vous fier à la couleur.

  • Synchronisé

    À jour avec la source.

  • Synchronisation en cours

    Une exécution est en cours. Vous pouvez l’annuler.

  • Divergent

    L’historique de la source ne correspond plus à la sauvegarde. Rien n’a été écrasé.

  • Échec

    La dernière exécution a échoué. BareKeep en explique la cause en termes simples et réessaie avec un délai croissant.

  • En pause

    Mis en pause volontairement. La synchronisation manuelle fonctionne toujours.

Compatible avec les hébergeurs Git que vous utilisez.

Les sources et les cibles de sauvegarde partagent la même liste de plateformes : un serveur Gitea ou Forgejo peut donc servir pour l’une comme pour l’autre.

  • GitHub
  • GitLab
  • Gitea
  • Forgejo
  • Instances auto-hébergées
  • Toute URL Git https

Une configuration en trois étapes.

  1. Collez l’adresse d’un dépôt

    BareKeep reconnaît la plateforme, le propriétaire et le nom du dépôt à partir d’une adresse https ou ssh.

  2. Choisissez un dossier et un jeton

    Indiquez où le miroir sera stocké sur votre Mac. Le jeton va directement dans le trousseau d’accès.

  3. Ajoutez une cible de sauvegarde (facultatif)

    Indiquez à BareKeep votre Gitea, Forgejo, GitLab ou GitHub. Il crée les dépôts privés à votre place et envoie les données après chaque synchronisation.

Pour vérifier, comparez-la avec le résultat de shasum -a 256 sur le fichier téléchargé.

Ouvrez le dmg et faites glisser BareKeep dans Applications. BareKeep utilise le Git fourni avec macOS ; si ce Mac ne l’a pas encore, BareKeep propose d’installer les outils de ligne de commande pour développeurs. Une question ? Consultez la FAQ.
