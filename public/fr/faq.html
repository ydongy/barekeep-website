Questions fréquentes

Vous ne trouvez pas votre réponse ? BareKeep explique les échecs en termes simples dans le journal des exécutions et sur la carte d’état du miroir. Ouvrez d’abord le miroir.

Notions de base

Qu’est-ce que BareKeep ?

Une app de barre des menus macOS qui garde des miroirs de vos dépôts GitHub, GitLab, Gitea et Forgejo sur votre Mac, et peut les envoyer vers votre propre serveur Git comme sauvegarde externe. Chaque miroir est un dépôt Git complet que vous pouvez cloner à tout moment.

De quoi ai-je besoin ?

D’un Mac avec macOS 26.0 ou ultérieur, et de Git. BareKeep utilise le Git fourni avec macOS ; si les outils de ligne de commande pour développeurs sont absents, BareKeep affiche une page qui les installe pour vous (environ 1 Go, depuis Apple). Les miroirs et les réglages ne sont pas modifiés tant que Git est absent, et la synchronisation reprend une fois Git installé.

Dois-je payer BareKeep ?

BareKeep propose une version gratuite qui gère jusqu’à 3 miroirs, et Pro, un achat unique (sans abonnement) sans cette limite. Une licence Pro couvre toutes les versions 1.x. Consultez les tarifs.

Puis-je utiliser BareKeep sur plusieurs Mac ?

Oui. La version gratuite fonctionne sur tous les Mac que vous possédez ou contrôlez. Une clé de licence Pro peut être active sur 2 de vos Mac en même temps ; pour l’utiliser sur un autre, désactivez-la d’abord dans Réglages › Licence sur l’un des deux.

Puis-je obtenir un remboursement ?

Oui, dans les 14 jours suivant l’achat de Pro, sans avoir à donner de motif. Les règles figurent dans la Politique de remboursement.

Que deviennent mes miroirs si ma licence cesse de fonctionner ?

Rien de ce que vous avez déjà mis en miroir ou sauvegardé n’est supprimé, et les miroirs présents sur votre disque restent lisibles. BareKeep repasse à la version gratuite : les 3 premiers miroirs continuent de se synchroniser, et les autres restent en place mais ne sont plus synchronisés tant que vous ne passez pas à Pro.

BareKeep modifie-t-il mes dépôts sur GitHub ou GitLab ?

Non. Les données circulent dans un seul sens : source, puis ce Mac, puis sauvegarde. BareKeep n’envoie jamais rien vers la source.

Quels hébergeurs Git sont compatibles ?

GitHub, GitLab, Gitea, Forgejo (y compris codeberg.org), les instances auto-hébergées des trois derniers, et toute URL Git https. Ajoutez d’abord une instance auto-hébergée dans Réglages › Plateformes ; elle peut ensuite servir de source ou de cible de sauvegarde.

Comment obtenir de l’aide ?

Commencez par le journal d’exécution et la carte d’état du miroir concerné : ils expliquent les échecs en termes simples. Si cela ne suffit pas, écrivez à support@barekeep.com en indiquant ce qu’affiche la carte d’état. N’envoyez jamais de jeton d’accès.

Synchronisation et sauvegardes

Comment fonctionne la synchronisation ?

Synchroniser maintenant lance un miroir immédiatement ; un calendrier les lance automatiquement. Les exécutions en échec sont relancées avec un délai croissant, et le journal des exécutions ainsi que la sortie de chacune se trouvent sur la page de détail du miroir. Mettre en pause la synchronisation arrête les exécutions automatiques ; la synchronisation manuelle fonctionne toujours.

Comment fonctionne la sauvegarde ?

Ajoutez une ou plusieurs cibles de sauvegarde (Gitea, Forgejo, GitLab ou GitHub) et choisissez, pour chaque miroir, celles vers lesquelles il envoie ses données. Quand la plateforme dispose d’une API, BareKeep crée le dépôt privé pour vous. La sauvegarde est facultative : sans cible, le miroir reste sur ce Mac.

Que signifie « Divergent » ?

La sauvegarde contient des commits absents de ce miroir, par exemple après un force-push sur la source. Pour ne pas les écraser, BareKeep n’envoie rien et suspend la synchronisation automatique de ce miroir. Vérifiez la sauvegarde, ou choisissez Écraser avec la source… pour réinitialiser ses branches et ses tags afin qu’ils correspondent à la source. Les commits présents uniquement dans la sauvegarde ne seront plus référencés : copiez donc le dossier local d’abord si vous souhaitez les conserver.

Confidentialité et sécurité

Où mon jeton d’accès est-il stocké ?

Uniquement dans le trousseau d’accès de votre Mac, une entrée par source et par cible de sauvegarde. Il n’est écrit ni dans des fichiers ni dans des journaux, et n’apparaît ni dans les lignes de commande ni dans les variables d’environnement ; il est transmis à git par un tube.

BareKeep collecte-t-il des données ?

Ni télémétrie, ni rapports de plantage, ni compte. Les seules données que BareKeep envoie sont la vérification des mises à jour et, si vous achetez Pro, votre clé de licence et un libellé d’appareil au prestataire de paiement. La Politique de confidentialité énumère toutes les adresses auxquelles BareKeep se connecte.

Comment BareKeep se met-il à jour ?

BareKeep recherche les nouvelles versions une fois par jour et à votre demande (vérification quotidienne désactivable dans les réglages) et les installe dans l’app après votre confirmation. Les mises à jour sont gratuites avec les deux formules. L’historique de chaque version se trouve dans les Nouveautés.
