A private code archive for your Mac

A private code vault that never goes offline.

BareKeep keeps your GitHub and GitLab repositories mirrored on your Mac, and can push them to your own Git server as an off-site backup.

Your repositories, your machines.

  • Read-only on the source

    Data only flows source, then this Mac, then backup. BareKeep never writes back to GitHub or GitLab.

  • Tokens stay in the keychain

    Access tokens live in your Mac’s keychain, one per source and per backup target, and are handed to git through a pipe.

  • Nothing is collected

    No telemetry, no crash reports, no account. Mirrors and run history stay on your Mac.

  • A real Git repository

    Every mirror is a complete bare repository on a folder you choose. Clone from it any time, even offline.

When histories diverge, it stops and asks.

The backup only accepts fast-forward pushes. If the source was force-pushed, BareKeep keeps the backup as it is, pauses automatic sync for that mirror, and lets you decide whether to overwrite it from the source.

Every mirror has a lamp.

The shape tells you the state, so you can read it without relying on color.

  • Synced

    Up to date with the source.

  • Syncing

    A run is in progress. You can cancel it.

  • Diverged

    The source history no longer matches the backup. Nothing was overwritten.

  • Failed

    The last run failed. BareKeep says why in plain words and retries with backoff.

  • Paused

    Paused on purpose. Manual sync still works.

Works with the Git hosts you use.

Sources and backup targets share the same platform list, so a Gitea or Forgejo server can be either.

  • GitHub
  • GitLab
  • Gitea
  • Forgejo
  • Self-hosted instances
  • Any https Git URL

Set up in three steps.

  1. Paste a repository address

    BareKeep recognizes the platform and the owner and repository name from an https or ssh address.

  2. Choose a folder and a token

    Pick where the mirror lives on your Mac. The token goes straight into the keychain.

  3. Add a backup target (optional)

    Point BareKeep at your Gitea, Forgejo, GitLab or GitHub. It creates private repositories for you and pushes after each sync.

Download BareKeep

BareKeep is a menu bar app for macOS. Mirrors run in the background and the main window shows every run.

For macOS 26.0 or later.

Open the dmg and drag BareKeep to Applications. BareKeep uses the Git that comes with macOS; if this Mac does not have it yet, BareKeep offers to install the Command Line Developer Tools. Questions? Read the FAQ.
