Perguntas frequentes

Não encontrou sua resposta? O BareKeep explica as falhas em palavras simples no registro de execuções e no cartão de status do espelho. Comece abrindo o espelho.

Básico

O que é o BareKeep?

Um app da barra de menus do macOS que mantém espelhos dos seus repositórios do GitHub, GitLab, Gitea e Forgejo no seu Mac e pode enviá-los ao seu próprio servidor Git como backup externo. Cada espelho é um repositório Git completo do qual você pode clonar a qualquer momento.

O que eu preciso?

Um Mac com macOS 26.0 ou posterior e o Git. O BareKeep usa o Git que acompanha o macOS; se as Command Line Developer Tools estiverem ausentes, o BareKeep mostra uma página que as instala para você (cerca de 1 GB, da Apple). Espelhos e ajustes ficam intactos enquanto o Git estiver ausente, e a sincronização continua assim que ele for instalado.

Preciso pagar pelo BareKeep?

O BareKeep tem uma versão gratuita que gerencia até 3 espelhos e o Pro, uma compra única (sem assinatura) sem esse limite. Uma licença Pro cobre todas as versões 1.x. Veja Preços.

Posso usar o BareKeep em mais de um Mac?

Sim. A versão gratuita funciona em todos os Macs que você possui ou controla. Uma chave de licença Pro pode estar ativa em 2 dos seus Macs ao mesmo tempo; para usá-la em outro, primeiro desative-a em Ajustes › Licença em um dos dois.

Posso pedir reembolso?

Sim, em até 14 dias após a compra do Pro, sem precisar de motivo. As regras estão na Política de Reembolso.

O que acontece com os meus espelhos se a minha licença deixar de funcionar?

Nada do que você já espelhou ou salvou em backup é apagado, e os espelhos no seu disco continuam legíveis. O BareKeep volta para a versão gratuita: os 3 primeiros espelhos continuam sincronizando, e os demais ficam onde estão, mas não são sincronizados até você fazer o upgrade.

O BareKeep altera meus repositórios no GitHub ou no GitLab?

Não. Os dados só fluem da origem para este Mac e depois para o backup. O BareKeep nunca envia nada para a origem.

Quais hosts Git funcionam?

GitHub, GitLab, Gitea, Forgejo (incluindo codeberg.org), instâncias auto-hospedadas dos três últimos e qualquer URL Git https. Adicione antes uma instância auto-hospedada em Ajustes › Plataformas; depois disso, ela pode ser uma origem ou um destino de backup.

Como obtenho ajuda?

Comece pelo log de execução e pelo cartão de status do espelho com problema: eles explicam as falhas em linguagem simples. Se isso não ajudar, escreva para support@barekeep.com e informe o que o cartão de status mostra. Nunca envie um token de acesso.

Sincronização e backups

Como funciona a sincronização?

Sincronizar agora executa um espelho imediatamente; um agendamento os executa automaticamente. Execuções com falha tentam de novo com backoff, e o registro de execuções e a saída de cada uma ficam na página de detalhes do espelho. Pausar sincronização interrompe as execuções automáticas; a sincronização manual continua funcionando.

Como funciona o backup?

Adicione um ou mais destinos de backup (Gitea, Forgejo, GitLab ou GitHub) e escolha, para cada espelho, para quais deles ele envia. Onde a plataforma tem API, o BareKeep cria o repositório privado para você. O backup é opcional: sem um destino, o espelho fica apenas neste Mac.

O que significa “Divergente”?

O backup tem commits que este espelho não tem, por exemplo depois de um force-push na origem. Para não sobrescrevê-los, o BareKeep não envia e pausa a sincronização automática daquele espelho. Verifique o backup ou escolha Sobrescrever com a origem… para redefinir seus branches e tags de acordo com a origem. Os commits que existem só no backup deixam de ser referenciados, então copie antes a pasta local se quiser mantê-los.

Privacidade e segurança

Onde meu token de acesso fica armazenado?

Somente no Chaveiro do seu Mac, uma entrada por origem e por destino de backup. Ele não é gravado em arquivos nem em logs e não aparece em linhas de comando nem em variáveis de ambiente; é entregue ao git por um pipe.

O BareKeep coleta algum dado?

Sem telemetria, sem relatórios de falhas, sem conta. Os únicos dados que o BareKeep envia são a verificação de atualizações e, se você comprar o Pro, a sua chave de licença e uma identificação do dispositivo ao provedor de pagamentos. A Política de privacidade lista todos os endereços aos quais o BareKeep se conecta.

Como o BareKeep se atualiza?

O BareKeep procura novas versões uma vez por dia e quando você pede (desative a verificação diária em Ajustes) e as instala no app depois que você confirma. As atualizações são gratuitas nos dois planos. O histórico de cada versão está em Histórico.
