Um arquivo de código privado para o seu Mac

Um cofre de código privado que nunca fica offline.

O BareKeep mantém seus repositórios do GitHub e do GitLab espelhados no seu Mac e pode enviá-los ao seu próprio servidor Git como backup externo.

Seus repositórios, suas máquinas.

  • Somente leitura na origem

    Os dados só fluem da origem para este Mac e depois para o backup. O BareKeep nunca grava de volta no GitHub ou no GitLab.

  • Tokens ficam no Chaveiro

    Os tokens de acesso ficam no Chaveiro do seu Mac, um por origem e por destino de backup, e são entregues ao git por um pipe.

  • Nada é coletado

    Sem telemetria, sem relatórios de falhas, sem conta. Espelhos e histórico de execuções ficam no seu Mac.

  • Um repositório Git de verdade

    Cada espelho é um repositório bare completo, em uma pasta que você escolhe. Clone a partir dele quando quiser, até offline.

Quando os históricos divergem, ele para e pergunta.

O backup só aceita pushes fast-forward. Se a origem sofreu um force-push, o BareKeep mantém o backup como está, pausa a sincronização automática daquele espelho e deixa você decidir se quer sobrescrevê-lo a partir da origem.

Todo espelho tem uma luz.

A forma indica o estado, então você pode entendê-lo sem depender da cor.

  • Sincronizado

    Atualizado com a origem.

  • Sincronizando

    Uma execução está em andamento. Você pode cancelá-la.

  • Divergente

    O histórico da origem não coincide mais com o backup. Nada foi sobrescrito.

  • Falhou

    A última execução falhou. O BareKeep explica o motivo em palavras simples e tenta de novo com backoff.

  • Pausado

    Pausado de propósito. A sincronização manual continua funcionando.

Funciona com os hosts Git que você usa.

Origens e destinos de backup compartilham a mesma lista de plataformas, então um servidor Gitea ou Forgejo pode ser qualquer um dos dois.

  • GitHub
  • GitLab
  • Gitea
  • Forgejo
  • Instâncias auto-hospedadas
  • Qualquer URL Git https

Configure em três passos.

  1. Cole o endereço de um repositório

    O BareKeep reconhece a plataforma, o proprietário e o nome do repositório a partir de um endereço https ou ssh.

  2. Escolha uma pasta e um token

    Defina onde o espelho fica no seu Mac. O token vai direto para o Chaveiro.

  3. Adicione um destino de backup (opcional)

    Aponte o BareKeep para o seu Gitea, Forgejo, GitLab ou GitHub. Ele cria repositórios privados para você e envia após cada sincronização.

Baixe o BareKeep

O BareKeep é um app da barra de menus para macOS. Os espelhos rodam em segundo plano e a janela principal mostra cada execução.

Para macOS 26.0 ou posterior.

Baixar


Para verificar, compare com a saída de shasum -a 256 no arquivo baixado.

Abra o dmg e arraste o BareKeep para Aplicativos. O BareKeep usa o Git que acompanha o macOS; se este Mac ainda não o tiver, o BareKeep oferece instalar as Command Line Developer Tools. Dúvidas? Leia o FAQ.

Preço

O BareKeep tem uma versão gratuita que gerencia até 3 espelhos e o Pro, uma compra única sem limite. Uma licença Pro cobre todas as versões 1.x. O preço é exibido aqui no lançamento.
